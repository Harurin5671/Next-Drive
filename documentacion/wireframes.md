# Wireframes - Next Drive

## Instrucciones para Draw.io

Los siguientes wireframes son descripciones textuales que puedes usar para recrear en draw.io:
1. Abre [draw.io](https://app.diagrams.net/)
2. Crea un nuevo diagrama
3. Usa las formas rectangulares para representar secciones
4. Agrega texto para etiquetar cada sección
5. Usa colores diferentes para distinguir secciones principales

## Guía de Colores para Draw.io

- **Header**: #FFFFFF (blanco) con borde inferior
- **Hero/Page Header**: Gradiente #F3F8FD a #E3EFFA (azul claro)
- **Secciones principales**: #FFFFFF (blanco)
- **Secciones alternas (surface)**: #F1F5F9 (gris muy claro)
- **Footer**: #12324F (azul oscuro)
- **Promociones**: #FFF7ED (naranja muy claro)
- **Cards**: #FFFFFF (blanco) con borde #E2E8F0
- **Botones primarios**: #1F6FB2 (azul)
- **Botones outline**: Borde #1F6FB2, fondo transparente
- **Texto principal**: #1E293B (gris oscuro)
- **Texto secundario**: #475569 (gris medio)

## Notas de Diseño

1. **Altura uniforme de cards**: Todas las cards en un grid deben tener la misma altura
2. **Navbar responsive**: En móvil se muestra un botón de menú hamburguesa
3. **Spacing**: Usar gap de 24px entre elementos, 55px de padding en secciones
4. **Tipografía**: Inter para cuerpo, Poppins para títulos
5. **Iconos**: Bootstrap Icons en toda la interfaz
6. **Imágenes**: Aspect ratio 4:3 para productos, 16:9 para videos
7. **Bordes**: 12px de border-radius en cards y elementos
8. **Sombras**: Sombras sutiles en cards para dar profundidad
